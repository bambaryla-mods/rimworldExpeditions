# Expeditions

### Every site, challenge and number in the mod: https://bambaryla-mods.github.io/rimworldExpeditions/

### Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3843741355

A RimWorld 1.7 mod by Bambaryła. Go looking for things instead of buying them: open the Expeditions window from any comms console, pick an opportunity on your colony's map, send a squad as they stand, and read the report when they come home.

Needs [Harmony](https://steamcommunity.com/workshop/filedetails/?id=2009463077). Optional support for Vehicle Framework and [LFS] UI Rethemed.

# Building

- The mod: `dotnet build Source/Expeditions.csproj` writes `1.7/Assemblies/Expeditions.dll`. Tests: `dotnet test Source/Tests`.
- The player site: see [site/README.md](site/README.md).
